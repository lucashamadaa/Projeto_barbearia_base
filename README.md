Barbershop Website 💈

A portfolio barbershop website built with HTML, CSS, and JavaScript, featuring a modern dark aesthetic with a full-screen background, animated border, custom cursor, and smooth interactions.
Features

- Responsive layout for desktop and laptop screens
- Animated border effect
- Custom cursor
- WhatsApp contact button
- Services pricing section
- Business hours display

About
This project is currently a static portfolio website for a barbershop. Over time, with further improvements and new features, it will evolve into a full dashboard — including appointment scheduling, client management, and more.
Tech Stack

- HTML5
- CSS3
- JavaScript
